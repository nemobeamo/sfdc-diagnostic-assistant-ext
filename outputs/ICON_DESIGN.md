# Extension icon

Generated with the built-in image-generation tool. The full-size selected artwork is saved as `outputs/extension-icon.png`. Transparent PNG sizes for toolbar and extension management are saved as `extension/icons/icon-16.png`, `icon-32.png`, `icon-48.png`, and `icon-128.png`. Both manifest icons and the toolbar action use these files.

## Final prompt

Use case: logo-brand. Asset type: a single square browser extension app icon for a Salesforce support diagnostic recorder, optimized to remain recognizable at 16, 32, 48 and 128 pixels. Create a polished contemporary icon: a deep navy rounded-square tile with a large clean luminous blue cloud silhouette, and one bold white diagnostic heartbeat/pulse line through the cloud. The cloud is original artwork, not a copy of an existing company's logo. Strong geometric silhouette, chunky strokes, exceptional contrast, subtle restrained blue depth, generous but tight safe margins. Straight-on flat app icon view, centered and perfectly square. Actual transparent background outside the rounded tile, with no surrounding shadow or white canvas. No words, no letters, no tiny details, no extra symbols, no mockup, no border around the canvas. Deliver only the finished icon.
